A few things I've built

Real tools for real problems, from idea to working build, edge cases included.

01

Complexity Assessment Agent Skill

The problem: PMs assessed project complexity by gut feel, with no shared framework. Risk was handled inconsistently from one project to the next, and every plan carried hidden manual overhead.

My approach: I built a Claude Code agent skill that reads the internal Knowledge Base in real time, checks a project across six complexity dimensions, and drafts an action plan for each risk it finds. Guardrails keep answers grounded in the knowledge base to prevent hallucination.

The result: A consistent, repeatable complexity read to support planning review in H1 2026. It was paused when I moved to a new team in Q3, but it's where I learned agentic workflow design, which I now apply to the Data Mart intake pipeline and PJ Agent.

Internal Shopee system. Design, grounding approach, and evaluation are mine and I'm glad to whiteboard the full design in an interview.

Agent SkillRAG / KBGuardrailsAgentic Design
02

POP Business Review Tracker

The problem: Five Marketplace product lines, 25+ teams in total, had zero cross-team visibility into how long business reviews were taking at each approval gate.

What I built: A Python pipeline + Flask dashboard that pulls P0/P1 request data from the internal POP API, tracks every request from submit to live, and writes it all into a shared Google Sheet with aging alerts. This was the first Python I ever wrote.

Internal tool on Shopee data, so no public link. Happy to walk through the pipeline design and the Sheets integration in an interview.

PythonFlaskGoogle Sheets APIData Pipeline
03

Meeting Attendee Resolver

The problem: Scheduling cross-team meetings meant manually cross-referencing org charts, tech stacks, and availability: slow and error-prone.

What I built: A web portal + Python server + SeaTalk bot that resolves the right attendees by meeting purpose and team, ranks time slots by preference, and sends a draft invite via bot DM with a pre-filled Google Calendar link.

Built on internal org and tooling data, so it stays private. The resolver logic and bot flow are mine to walk through.
